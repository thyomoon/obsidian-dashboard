# 옵시디언 대시보드

구글 드라이브에 있는 옵시디언 볼트(`Taylor 2 Brain`)를 읽고 쓰는 웹 앱. 집 맥 · 회사 맥 · 아이폰에서 같은 주소로 연다.

- **할 일** — 데일리 로그의 `- [ ]`를 모아 보여준다. 안 한 것만 / 완료 포함. 체크하면 원본 로그의 그 줄만 `[x]`로 바뀐다. 날짜 칩을 누르면 그날 로그.
- **빠른 한 줄** — 「할 일」은 오늘 로그 `## 남은 일`에 `- [ ] …`, 「아이디어」는 `## 새로운 아이디어`에 `- …`로 들어간다. 오늘 로그가 없으면 `Templates/데일리 로그.md`로 만든다(`author: Taylor`, `model` 줄 없음).
- **데일리 로그 · 최근 7일** — 누르면 로그 전체. 오늘 로그는 「내 한 줄」 · 「오늘의 일기」를 그 자리에서 쓴다(멈추고 1.2초 뒤 저장).
- **달력** — 안 한 할 일이 남은 날(빨간 점) · 일정 있는 날(초록 네모). 날짜를 누르면 그날 일정과 로그.
- **오늘 일정** — 구글 캘린더(읽기만).

## 지키는 것

- 쓰는 곳은 `2. Area of Responsibility/My Think/0. 데일리 로그/` 폴더 안의 파일뿐이다. 다른 파일은 코드에서 막는다(`js/google.js`의 `writable`).
- 바꾸는 것은 체크 표시, 넣은 한 줄, 「내 한 줄」 · 「오늘의 일기」 칸, 프론트매터 `modified` 시각뿐. 칸 안의 `<!-- -->` 주석은 남긴다.
- 쓰기 전에 늘 최신 파일을 다시 받아서 고친다. 「내 한 줄」 · 「오늘의 일기」가 다른 곳(옵시디언 · 다른 기기)에서 바뀌었으면 덮어쓰지 않고 알린다.
- 날짜 · 시각은 샌프란시스코 현지 시각.
- 서버가 없다. 브라우저가 구글 API를 직접 부르고, 로그인 토큰은 그 브라우저에만 남는다.

## 처음 한 번: 설정

### 1. 구글 클라우드 (약 20분)

1. https://console.cloud.google.com → 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 `obsidian-dashboard`.
2. **API 및 서비스 → 라이브러리**에서 **Google Drive API**, **Google Calendar API**를 각각 「사용」.
3. **Google 인증 플랫폼(OAuth 동의 화면)** → 시작하기
   - 앱 이름 `옵시디언 대시보드`, 지원 이메일 = 내 gmail
   - 대상: **외부(External)**
   - **대상 → 테스트 사용자**에 `hyobeen.moon@gmail.com` 추가. 게시 상태는 **테스트**로 둔다(나만 쓴다).
4. **클라이언트 → 클라이언트 만들기** → 유형 **웹 애플리케이션**
   - 승인된 JavaScript 원본: `https://thyomoon.github.io`
   - 승인된 리디렉션 URI: `https://thyomoon.github.io/obsidian-dashboard/` (끝의 `/`까지 똑같이)
5. 만들어진 **클라이언트 ID**(`….apps.googleusercontent.com`)를 `js/config.js`의 `CLIENT_ID`에 붙여넣는다. 클라이언트 보안 비밀(secret)은 쓰지 않는다 — 어디에도 넣지 말 것.

### 2. GitHub Pages

1. GitHub에 새 저장소 `obsidian-dashboard` (무료 계정은 Pages를 쓰려면 **Public**). 코드만 올라가고 볼트 내용은 올라가지 않는다.
2. 이 폴더의 파일을 올린다.
3. 저장소 **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save.
4. 1~2분 뒤 `https://thyomoon.github.io/obsidian-dashboard/`가 열린다.

### 3. 첫 로그인

- 「구글로 로그인」 → **「Google에서 확인하지 않은 앱」** 화면이 나오면 → 고급 → 계속. (내가 만든 테스트 앱이라 그렇다.)
- 드라이브 · 캘린더 권한을 허용한다.
- 로그인은 한 시간쯤 유지된다. 지나면 다시 「구글로 로그인」을 누르면 된다.

### 4. 아이폰

Safari로 주소를 열고 → 공유 → **홈 화면에 추가**. 앱처럼 열린다.

## 고칠 때

- 볼트 경로 · 폴더 이름이 바뀌면 `js/config.js`.
- 미리보기(구글 연결 없이, 실제 로그 사본으로): `tests/preview.sh` → 크롬에서 열림. 로그 사본은 임시 폴더에만 생긴다.
- 화면 찍기: `tests/preview.sh shot <폴더>`
- 로그 읽기 · 쓰기 테스트: `tests/run.sh` (볼트를 읽기만 한다)

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` · `css/style.css` | 화면 |
| `js/config.js` | 클라이언트 ID · 볼트 경로 |
| `js/markdown.js` | 로그 md 읽기 · 고치기(순수 함수) |
| `js/google.js` | 로그인 · 드라이브 · 캘린더 |
| `js/app.js` | 화면 그리기 · 조작 |
| `tests/` | 파서 테스트 · 미리보기 |
